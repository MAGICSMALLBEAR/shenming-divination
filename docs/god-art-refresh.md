| 種類 | 路徑 | 尺寸 | 用途 |
|------|------|------|------|
| card | `assets/images/gods/generated/cards/<前綴>-card.png` | 1024 × 1536 | 神明列表、詳細頁 |

## 三、風格規格（對齊 #51–#59）

先打開 `generated/cards/huangdaxian-card.png`、`chegong-card.png`、`shijiamounifo-card.png` 看實際效果。

- 寫實彩繪，帶廟宇神像的質感；暖色燭光加上神明頭後的金色光環。

- 主題色取自 `gods.ts`，讓服飾、光環或光影帶有該色調（見第五節）。
- **禁止**：文字、浮水印、簽名、邊框、UI 元素、現代物品。

## 七、驗收

1. **沒有重複圖**（應無輸出）：
   ```bash
   cd assets/images/gods/generated
   md5sum cards/*.png soft/*.png closeups/*.png | awk '{print $1}' | sort | uniq -d
   ```
2. **尺寸**：card、soft 全部 1024×1536（包含 #28–#31），closeup 全部 1024×1280。
3. **closeup 不是 card 的上段裁切**：下面的腳本對每位神明比較 closeup 與 card 上方 1280 像素，平均差異應明顯大於 0（現有合格素材約 30–45），等於 0 代表只是裁切。
   ```python
   from PIL import Image, ImageStat, ImageChops
   import glob, os
   for f in sorted(glob.glob('cards/*-card.png')):
       n = os.path.basename(f)[:-9]
       c = Image.open(f).convert('RGB'); k = Image.open(f'closeups/{n}-closeup.png').convert('RGB')
       d = sum(ImageStat.Stat(ImageChops.difference(c.crop((0, 0, 1024, 1280)), k)).mean) / 3
       print(f'{n:22} {d:5.1f}', '<<< 疑似直接裁切' if d < 5 else '')
   ```
4. **風格一致**：把 59 位的 card 縮圖拼成一張總覽，與 #51–#59 並排比較亮度、色調與畫風。
5. **程式檢查**：`npx tsc --noEmit`、`npm run lint`、`npx jest` 全部通過（目前基準是 30 個測試檔、222 個測試）。
6. **人工目視**：神明列表、詳細頁、廟宇頁、上香畫面、籤詩卡片。逐一確認每位神明的造型符合第五節的重點，而且和註明「要區分」的神明分得出來。
