# 尚未收錄的獨立籤本：候選資料與取得順序

查核日：2026-10-28（臺灣時間）。本表對照 `src/data/oracleCatalog.ts`、各籤詩資料檔及既有研究筆記；「未收錄」指 **App 尚未提供該廟的獨立籤本**，不代表該神明完全沒有抽籤功能。既有的六十甲子、觀音百首、雷雨師百首及神明專屬編輯解讀，不能算成下表的廟本。

接入 App 前的資料與功能缺口，見[七套候選籤本現況與功能缺口](oracle-seven-editions-gap-review-2026-10-28.md)。

這次整理的是籤本來源、數量、版次、取得狀態與下一步。七套的逐號來源及缺口已匯入[機讀建檔清冊](../src/data/poems/oracleCandidateEntryRegister.json)；紫竹寺另有[28 首逐首來源索引](../src/data/poems/zizhuGuanyinDraft.ts)。沒有把網頁籤文或廟方解說複製到 App，也沒有修改抽籤母體。

## 三、逐首建檔欄位與待辦

建議一套籤本一個來源索引，逐首紀錄：`systemId`、`temple`、`edition`、`number`、`sourceUrl`、`sourceImageUrl`、`originalText`、`variants`、`ritualMapping`、`officialExplanation`、`appInterpretation`、`rightsStatus`、`verifiedAt`、`reviewer`。目前完成**七套逐號清冊**；上表不表示所有籤詩都已逐字轉錄或授權。

1. 紫竹寺 28 首與文武廟月老 40 首已建立逐首來源索引；接著逐字校對原文、異文、首尾籤與特殊格式。
2. 慈鳳宮 100 首已取得官方 API 的逐號 `ad_id`；逐頁確認網址和原文，避免把廟方「詩解」直接當作 App 白話。
3. 大天后宮 27 首已有「三筊象順序 → 籤號 → 官方頁」對照；逐張影像校對原文。
4. 鎮安宮、宜蘭東嶽廟與廣澤尊王候選先取得廟方底本或權利人核定資料，再處理全文。
5. 藥籤按廟宇與科別建立典藏目錄；每一筆個別記錄來源和授權，並沿用[藥籤安全規格](chifu-dexing-medicine-lots-safety-spec.md)。
