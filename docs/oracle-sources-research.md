# 神明籤詩來源深度調查

> 調查日期：2026-10-16
> 目的：替 59 位神明逐一確認「有沒有自己的傳統籤」以及「有沒有足夠可靠的來源可以收錄」
> 收錄原則（沿用 2026-07-15 起的規則）：只收能逐字比對的真實籤文，找不到可靠來源就不收，**不自行補寫籤文**

## 一、摘要

1. **《正統道藏》靈籤原典可以直接取得全文**（Kanripo 漢籍リポジトリ在 GitHub 上的數位化版本），共 8 部。這是本次最重要的發現：
   - 《護國嘉濟江東王靈籤》100 首，**內容就是 App 用量最多的雷雨師百首（關帝籤）**，可以拿原典逐字校對現有資料。
   - 《玄天上帝感應靈籤》49 首，可以取代玄天上帝目前用的「二十八宿值日歌訣」（那是擇日口訣，不是籤）。
   - 《靈濟真君注生堂靈籤》64 首、《九天衛房聖母元君靈應寶籤》99 首，都是求子安產主題。
2. **找到多套台灣廟宇在用的專屬籤**，正是 2026-07 被刪掉的那批假籤當初想做、但沒有真籤文的系統：天后宮一百籤（媽祖）、保生大帝六十籤（大龍峒保安宮）、註生娘娘三十籤、指南宮呂祖六十籤、玄天上帝五十一籤。
3. **今天上線的黃大仙籤，用第 4 個來源複查後發現約 15 處讀法需要修正**，其中至少 4 處可以確定是錯字，見第四節。
4. **4 套籤的名稱和實際首數不符**（例如「媽祖天后百籤」實際是 60 首），見第五節。

## 二、來源分級

| 等級 | 說明 | 例子 |
