## 現行流程

```text
選神 → 輸入問題 → 上香（點香／插香）→ 靜心 5 秒
→ 選擇求籤方式
  ├─ 傳統：擲筊取得聖筊 → 搖籤筒 → 顯示籤詩與解籤
  ├─ 自動：擲筊取得聖筊 → 自動開籤 → 顯示籤詩與解籤
  ├─ 直接：直接開籤 → 顯示籤詩與解籤
  └─ 報數：輸入數字 → 開籤 → 顯示籤詩與解籤
```

## 流程觀察

1. **擲筊的位置與嚴謹模式不符合主要儀式敘事。**
   - 現在的預設是抽籤前出現一次聖筊便進入搖籤；嚴謹模式則要求抽籤前累積三次聖筊。
   - 較完整且容易理解的台灣廟宇求籤脈絡通常應拆成兩段：先擲筊請示「是否可求籤」，抽出籤號後再擲筊確認「是否為此支籤」，確認通常以連續三次聖筊為完成。
   - 現行流程少了抽後驗籤，因此使用者看見籤號後直接進解籤，儀式上會顯得尚未收束；建議將「三次聖筊」從抽前嚴謹模式，改為抽後的籤詩確認步驟。

2. **四種方式混在同一層，容易讓快捷方式看起來像正式流程。**
   - 「傳統擲筊搖籤」應作為預設且明確標示為完整儀式。
   - 自動開籤、直接點籤、心中報數較適合收在「快捷／無障礙方式」區塊；其說明需寫清楚它們省略了哪些儀式步驟。

3. **上香與靜心分段本身合理，但結束訊號可再更明確。**
   - 上香完成後目前約 0.95 秒即自動切換到 5 秒靜心畫面，使用者沒有明確的「香已安座」停留或自行進入下一步的確認。
   - 後續可改為：插香完成 → 讓三炷香與煙停留 → 顯示「合掌靜心，開始請示」按鈕；這會比自動跳轉更有節奏。
