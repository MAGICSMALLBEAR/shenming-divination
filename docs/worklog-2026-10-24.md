### 3. 原生候選發佈流程

- `npm run release:rc -- --bump patch|minor|major|x.y.z`：調整 `app.json`／`package.json` 版本，並同步遞增 `ios.buildNumber` 與 `android.versionCode`，之後先 commit。
- `npm run release:rc`：要求工作區乾淨，跑型別、lint、單元測試、Web 匯出，產生 `docs/releases/v<版本>-rc.<n>.md`，內容包括測試 SHA、各檢查結果、自上一個候選版起的變更、A/I/T/W 真機紀錄連結、阻擋項目與建置指令。
- 設定頁「關於」底部顯示版本與 build 號，真機紀錄可以對應到候選紀錄。
- 目前會列出的阻擋項目：`android.package`、`ios.bundleIdentifier` 未設定（上架後不可更改，需要產品決定）、Sentry organization/project 未設定、真機紀錄未回填。
