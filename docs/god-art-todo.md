## 三、圖片放在哪、程式怎麼讀

每位神明有 3 種圖，放在三個資料夾：

| 種類 | 路徑 | 尺寸 | 用途 |
|------|------|------|------|
| card | `assets/images/gods/generated/cards/<前綴>-card.png` | 1024 × 1536（2:3） | 神明列表卡片、神明詳細頁 |
| soft | `assets/images/gods/generated/soft/<前綴>-soft.png` | 1024 × 1536（2:3） | 廟宇頁背景、抽籤動畫、神明顯聖畫面 |
| closeup | `assets/images/gods/generated/closeups/<前綴>-closeup.png` | 1024 × 1280（4:5） | 上香儀式、籤詩卡片上的頭像 |

程式讀圖片的地方有兩處，**兩處都要對**：

1. `src/data/gods.ts`：每位神明的 `image` 欄位，指向 card 圖。
2. `src/data/godImages.ts`：`godImagesById` 依 ID 列出 card／soft／closeup 三張圖。

目前 #51–#58 的 `gods.ts` 指向自己的同名檔（例如 `dijizhu-card.png`），但 `godImages.ts` 指向被借用的神明（例如 `fudezhengshen-card.png`）。所以**只覆蓋圖檔還不夠，`godImages.ts` 也要改**。

## 四、畫風規格（對齊現有 50 位神明）

參考範例：`周倉將軍`（`zhoucangjiangjun-card.png`／`-soft.png`／`-closeup.png`）、`媽祖`（`mazu-*`）。

- **整體風格**：寫實彩繪，帶廟宇神像質感；暖色燭光從正面或側上方打光，神明主體清楚。
- **背景**：昏暗的廟宇內殿，紅柱、雕花木作、燈籠或香爐；神明頭後有金色圓形光環或曼陀羅紋；淡淡的香煙繚繞。
- **構圖**：神明居中、直式構圖、正面或微側，臉部清楚，表情符合神格（慈悲、威嚴或慈祥）。
- **禁止**：任何文字、浮水印、簽名、邊框、UI 元素；不可出現現代物品。
- **檔案**：PNG、RGB、無透明背景。

三種圖的關係（依現有素材實測）：

- **card**：主圖，全身或膝上的立像／坐像。
- **soft**：與 card **同一張圖、同構圖**，亮度略降約 5%、對比略降，讓上面的文字較易閱讀。可以直接從 card 調整產生。
- **closeup**：同一位神明的胸像特寫，4:5，臉部在畫面上方約 1/3 處，頭頂留一點空間。可以從 card 裁切後放大重繪，也可以另外生成，但五官與服飾必須和 card 一致。

## 七、驗收方式

1. **沒有任何重複圖**：下面的指令不應輸出任何東西。

   ```bash
   cd assets/images/gods/generated
   md5sum cards/*.png soft/*.png closeups/*.png | sort | awk '{print $1}' | uniq -d
   ```

   注意：soft 是由 card 調整出來的，兩者的 md5 本來就會不同；如果有一組完全相同，表示 soft 忘了調整，或是又複製了別人的圖。

2. **尺寸正確**：card、soft 為 1024×1536，closeup 為 1024×1280。
3. **程式檢查**：`npx tsc --noEmit`、`npm run lint`、`npx jest` 全部通過（目前基準是 27 個測試檔、205 個測試）。
4. **人工目視**：打開 App 的神明列表、神明詳細頁、廟宇頁、上香畫面、籤詩卡片，逐一確認 9 位神明都顯示自己的圖，而且一眼就能和第五節列出的「要區分的神明」分辨。
