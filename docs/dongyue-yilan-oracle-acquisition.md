## 1. 本次採用的目標籤本

- **廟宇**：宜蘭東嶽廟
- **地址**：宜蘭縣宜蘭市中山路二段 299 號
- **官方登記電話**：03-932-2590
- **籤本名稱（暫定呈現）**：宜蘭東嶽廟二十八星宿籤
- **結構**：二十八首星宿籤 + 籤王；實際上架總首數、籤王抽取規則、籤號／星宿排序，均以廟方提供的底本為準。

蘭陽博物館記載，該廟以二十八星宿與四象排列組合成二十八首籤詩及籤王，且現存籤詩屬珍貴文物、印刷場已不再印製。本案因此不以網路轉錄本或自行創作補齊。

## 3. 對廟方的聯繫說明稿

您好，我們正在製作一款台灣民間信仰導覽與抽籤 App，希望以正確方式介紹宜蘭東嶽廟的二十八星宿籤與籤王文化。

我們不會自行編寫或以其他籤系冒稱東嶽廟籤詩。若廟方願意合作，想請教：

1. 是否可提供或協助拍攝完整籤本，包含二十八首與籤王？
2. 各籤的正式星宿名稱、排序、抽取與解籤方式為何？
3. 是否同意在 App 逐字轉錄籤詩，並以「宜蘭東嶽廟二十八星宿籤」標示來源？
4. App 另寫的白話說明，是否可在送審後以「App 編輯解讀」方式呈現？
5. 廟方希望如何署名、連結、標示授權範圍，或是否需提供紙本／電子合作同意書？

我們會在上線前提供完整逐首校對稿；在取得同意前，不會公開或上架任何廟方籤文。

## 4. 資料建檔格式

每一首籤建立下列欄位，所有原文與照片來源一一對應：

```ts
{
  number: 1,                         // 以廟方正式排序為準
  celestialMansion: '角',            // 廟方正式寫法
  fourSymbol: '青龍',                // 無明示則留空，不自行推定
  title: '...',
  poemText: '...',                   // 原文，逐字轉錄
  interpretation: '...',             // App 編輯，與原文分開
  sourceImageId: 'yilan-dongyue-...',
  transcriptionCheckedBy: ['廟方', 'App 校對者'],
}
```

籤王不可預設為第 29 首；待廟方確認它是獨立籤、抽籤前的規則籤，或另有使用方式後，再決定資料模型與介面。

## 5. 上架驗收門檻

1. 全套籤文 100% 具備可追溯原始影像或廟方核定文字。
2. 籤號／星宿名稱／四象分組與原本完全一致；不使用連號假設補缺。
3. 籤王規則已由廟方確認。
4. 每首籤至少兩次逐字校對；異體字、缺字與難辨字保留校勘紀錄。
5. App 顯示「原籤詩」與「App 白話解讀」兩層，不把編輯文字誤標為廟方解籤。
6. 使用權、署名與連結已核可，並更新 `oracleCatalog` 的版本標籤與來源說明。
7. 通過既有 `oracleAudit`：首數、籤號、必填解籤欄位與目錄資料均完整。

## 6. App 切換策略

在取得完整授權以前，#38 仍使用觀音靈籤作為**暫用通行籤系**，不得稱為「宜蘭東嶽廟籤」。

完成驗收後才新增獨立 `dongyueYilanPoems` 資料模組，並把 #38 的 `poemSystem` 切換為「宜蘭東嶽廟二十八星宿籤」。原觀音靈籤資料不刪除，以維持其他神明與既有抽籤紀錄的相容性。
