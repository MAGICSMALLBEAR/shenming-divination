# 池府千歲：虎尾德興宮藥籤典藏規格

> 狀態：來源與數位物件權利資訊已確認；**不納入一般抽籤或醫療建議功能**
>
> 建立日期：2026-10-22
>
> App 對象：#42 池府千歲

## 1. 已確認的來源

國家文化記憶庫收錄「虎尾德興宮池府千歲藥籤」系列，由衛生福利部國家中醫藥研究所的臺灣中醫藥醫療文化記憶保存推廣計畫建檔。

- 2026-10-23 逐筆盤點：國家文化記憶庫收錄第 1–120 首，連號無缺、無重複，物件 ID 為 598527–598664（中間夾雜其他系列的 ID）。前後相鄰 ID 為其他宮廟（砂崙腳巡天府）與無關文物，記憶庫內未見第 121 首以後。**120 首是否為德興宮全套，尚未經廟方確認。**
- 120 筆的權利標示一致：數位影像 PDM、說明文字 OGDL、建檔單位衛生福利部國家中醫藥研究所、年代皆為「年代不明」。
- 個別物件頁所示數位物件授權為 PDM；說明文字授權為 OGDL 1.0。每一筆收錄前仍應逐筆保留其頁面網址與授權標示。
- 藥籤內容包括傳統藥材、劑量與服用方式；部分條目提到硃砂等具有現代安全風險或禁用的材料。

## 2. 產品邊界

池府千歲的現行「六十甲子籤」保留作一般問事用途。虎尾德興宮藥籤只能以獨立的：

> **文化藥籤典藏：歷史文物與民間醫療文化說明，非處方、非診斷、非治療建議。**

形式呈現，不能取代現有抽籤，也不能依使用者症狀、年齡、疾病、孕期或用藥推薦任何籤、藥材、劑量或煎服方式。

## 3. 第一版內容範圍

第一版不呈現可操作的藥方文字，而建立安全的典藏目錄：

| 顯示 | 可以收錄 | 不得收錄／生成 |
|---|---|---|
| 文物資訊 | 籤號、文物名稱、年代欄位、來源、典藏連結、影像縮圖 | 從影像自行推測缺字或補寫藥方 |
| 文化背景 | 建檔單位原有的歷史介紹、授權與引用資訊 | 將歷史說明改寫為療效保證 |
| 安全資訊 | 「請勿依此自行配藥或服用」、「有不適請就醫」 | 症狀對應、劑量、替代療法、個人化解釋 |
| 導覽 | 連到國家文化記憶庫原始條目 | 抽出一首並顯示給使用者服用 |

## 4. 後續分期

### Phase A：安全典藏目錄（2026-10-23 已完成）

> 資料：`src/data/chifuMedicineLotArchive.ts`；頁面：`src/app/chifu-medicine-archive.tsx`（只從池府千歲神明頁進入）；測試：`__tests__/chifuMedicineLotArchive.test.ts` 檢查欄位白名單、1–120 連號，以及只有典藏頁與神明頁引用此資料。

1. 逐筆盤點文化記憶庫的實際首數與缺號。
2. 為每筆記錄：籤號、標題、物件 ID、原始網址、影像權利、描述文字權利、建檔單位與最後查核日。
3. 只在 App 的「池府千歲文化資料」頁提供目錄與外部原始連結。
4. 建立固定警語與緊急就醫提示；不讓它出現在首頁抽籤、語音問事、搜尋健康問題或 AI 解籤結果。

### Phase B：受審閱的學術導覽（需要外部專業）

必須先獲得中醫藥、藥學或醫療法規專業人員的內容審閱，才能考慮增加「古代藥材名詞」等教育說明；仍不得使使用者取得可執行處方。

### Phase C：原始方文數位典藏（暫不排期）

只有在取得文化機構與合格醫療／藥學審閱的書面意見、完成年齡與風險保護、並確認平台政策後才評估。即使啟動，也只宜在研究／典藏脈絡中受限制檢視。

## 5. App 建檔資料格式（Phase A）

```ts
type ChifuMedicineLotArchive = {
  lotNumber: number;
  title: string;
  sourceUrl: string;
  cultureMemoryObjectId: string;
  objectLicense: 'PDM' | 'needs-verification';
  descriptionLicense: 'OGDL-1.0' | 'needs-verification';
  reviewedAt: string;
  safetyStatus: 'catalog-only';
};
```

刻意不設 `prescription`、`dosage`、`indication` 或 `recommendedFor` 欄位，防止資料被誤接到抽籤結果、健康問答或 AI 回覆。

## 6. 上架驗收

1. 每筆都有原始條目網址與權利標示。
2. 所有入口都顯示「文化典藏，非醫療建議」；健康類問題不導向本資料庫。
3. 不含可直接執行的配方、劑量、服用法或療效敘述。
4. 不在使用者病急、懷孕、兒童、高齡、慢性病或用藥互動等情境提供指引。
5. 由醫療／藥學專業人員審閱後，才可擴展任何藥材解說。
